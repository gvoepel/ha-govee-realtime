# Govee Realtime for Home Assistant

A Home Assistant add-on repository with one add-on, **Govee Realtime**: per-LED realtime animations, a theme builder and
a preview page for the Govee Permanent Lights Pro (H706C), all over the local network.

## Install

Settings > Add-ons > Add-on Store > ⋮ > **Repositories**, add

    https://github.com/gvoepel/ha-govee-realtime

then install **Govee Realtime** and read its Documentation tab.
